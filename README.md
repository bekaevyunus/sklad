# Склад — учёт товаров

Приложение для учёта товара в магазине. Открывается в браузере на компьютере и на телефоне. На телефон его можно поставить как обычное приложение. Все устройства работают с одной базой, и изменения видны везде через несколько секунд.

## Что умеет

- **Продажа.** Сканируете товар, он попадает в корзину, жмёте «Продать», и остаток уменьшается.
- **Приход.** Сканируете поступивший товар и указываете количество. Если товара ещё нет в базе, сразу открывается форма добавления, а название приложение само ищет по штрих-коду в открытых базах (Open Food Facts, «Честный знак», barcode-list.ru и другие). Цены и количество вводятся вручную.
- **Товары.** Название, штрих-код, категория, фото, количество, закупочная и розничная цена, поиск, выгрузка остатков в Excel. Новый товар может добавить любой сотрудник — по штрих-коду или вручную.
- **Фото и карточка товара.** Фото подтягивается из базы штрих-кодов или снимается камерой телефона; по нажатию на товар открывается карточка с большим фото.
- **Категории — автоматически.** По названию и бренду: «Вода Пилигрим» → Напитки, «Антифриз Totachi» → Масла и антифризы. Категорию можно поправить вручную или придумать свою. Правила — в `public/categories.js`.
- **Отчёты** (только владелец): выручка, себестоимость, прибыль за любой период, что продаётся лучше, что заканчивается, отмена ошибочной продажи.
- **Сотрудники.** Владелец видит всё. Продавец продаёт, принимает и добавляет товар, но не видит закупочные цены, прибыль и отчёты и не может менять или удалять уже заведённые товары.
- **Сканирование:**
  - USB- или беспроводным сканером на компьютере: сканер работает как клавиатура, ничего настраивать не нужно;
  - камерой телефона: кнопка 📷.

## Установка на сервер

Нужен любой VPS с Linux (Ubuntu 22.04 или 24.04), например у Timeweb Cloud, Beget или Selectel, от 1 ГБ памяти. Обычно это 200–400 ₽ в месяц, оплата российской картой.

1. Подключитесь к серверу. На Windows откройте PowerShell и введите `ssh root@IP-сервера`, затем пароль из письма хостинга.
2. Выполните одну команду:
   ```bash
   bash <(curl -fsSL https://raw.githubusercontent.com/bekaevyunus/sklad/main/install.sh)
   ```
   Скрипт сам установит Docker, скачает приложение в `/opt/sklad` и спросит адрес сайта (Enter — адрес вида `1-2-3-4.sslip.io` по IP сервера) и пароль владельца.
3. Откройте в браузере адрес, который покажет скрипт, и войдите под своим именем и паролем.

**https обязателен:** без него браузер телефона не даст включить камеру. Caddy получает сертификат автоматически.

### Установить на телефон

- **Android (Chrome):** меню ⋮ → «Добавить на главный экран».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

### Обновление

```bash
bash /opt/sklad/install.sh
```
Данные и настройки при обновлении сохраняются.

### Резервная копия

Копия базы делается **каждую ночь** автоматически в `/opt/sklad/backups` и хранится 30 дней. Сделать копию вручную: `/opt/sklad/backup.sh`.
Чтобы скачать копию на свой компьютер, введите в PowerShell на компьютере:
```bash
scp root@IP-сервера:/opt/sklad/backups/* .
```

## Запуск на своём компьютере (Windows) вместо сервера

Компьютер становится сервером: на нём хранится база, а телефоны продавцов подключаются к нему по Wi-Fi.

1. Установите **Node.js LTS** с https://nodejs.org (кнопка LTS, затем «Далее» до конца).
2. На GitHub откройте репозиторий → зелёная кнопка **Code → Download ZIP**. Распакуйте архив, например в `C:\Sklad`.
3. Дважды щёлкните **start-windows.bat**. При первом запуске он попросит придумать имя и пароль владельца. Если Windows спросит про брандмауэр, нажмите **«Разрешить доступ»**.
4. В окне появятся адреса:
   - на этом компьютере — `http://localhost:3000`;
   - с телефона — `http://192.168.x.x:3000`. Телефон должен быть в том же Wi-Fi.

Окно не закрывайте: пока оно открыто, приложение работает. Чтобы сервер запускался сам при включении компьютера, нажмите `Win+R`, введите `shell:startup` и положите туда ярлык на `start-windows.bat`.

**Резервная копия:** запускайте `backup-windows.bat`, он кладёт копию базы в папку `backups`. Переносите её на флешку или в облако.

### Ограничения домашнего сервера

- Компьютер должен быть **включён**, пока работает магазин.
- Телефоны работают только в **том же Wi-Fi**. Подключиться из другого места не получится.
- **Камера телефона** без https не включится, потому что браузер запрещает её на адресах `http://192.168…`. Что делать:
  - **Android (Chrome):** откройте `chrome://flags/#unsafely-treat-insecure-origin-as-secure`, впишите адрес `http://192.168.x.x:3000`, переключите на **Enabled** и перезапустите Chrome. После этого камера заработает.
  - **iPhone:** так не получится. Сканируйте USB-сканером на компьютере или вводите код вручную.
- Адрес `192.168.x.x` может поменяться после перезагрузки роутера. Чтобы этого не было, закрепите IP за компьютером в настройках роутера (раздел «DHCP → резервирование адресов»).

## Запуск без сервера (для проверки)

На компьютере с Node.js 22.13 или новее:
```bash
ADMIN_PASSWORD=1234 npm start
```
Затем откройте http://localhost:3000. Камера в этом режиме работает только на самом компьютере, сканер — везде.
